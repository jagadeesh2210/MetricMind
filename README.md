# MetricMind

AI-powered governed metrics analytics and natural-language query dashboard.

## Overview

MetricMind allows users to ask natural-language questions about business metrics such as revenue, cost, margin, and margin percentage.

## Features

- Natural-language metric queries
- Governed metrics
- Revenue and margin calculations
- Regional breakdowns
- Interactive charts
- Conversational dashboard
- Query guardrails

## Example Queries

- What is the total revenue?
- Show margin by region
- Show revenue by region
- Show revenue in Q1 2026

## Tech Stack

- Next.js
- TypeScript
- React
- Node.js
- Chart visualization
- CSV-based sample data
- Vitest
